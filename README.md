# lnp-carrier-ai-prediction
AI prediction platform for LNP nucleic acid carriers, focusing on particle size, mRNA transfection efficiency and cellular biocompatibility in N2a and bEnd.3 cell lines to support rational formulation screening.

## Live Demo
👉 [Open the web app](https://lnp-glioma-virtual-lab.tao177282.chatgpt.site)

## Overview
This is an in-silico virtual experiment platform for LNP formulation screening.
Users can input LNP formulation parameters, run multi-model prediction, sort candidates and export results as CSV.

## Notice
All prediction results are for preliminary reference only. Optimized LNP formulations need validation by wet-lab cellular experiments.
